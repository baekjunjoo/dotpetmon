# 닷펫몬 (DotPetMon)

**시각장애 친화 턴제 몬스터 수집 RPG**

내가 트레이너 주인공. 알 부화로 랜덤 스타터를 받고, 여러 지역을 다니며 닷펫몬을 모으는 게임. 닷패드 위 촉각 시그너처로 각 종을 인식하고, 키운 펫으로 턴제 배틀하며, 친구와 트레이드.

> ℹ️ **DotPet과의 관계**: DotPet은 다마고치 스타일 케어 게임 (v0.9 라이브).
> 닷펫몬은 그 케어 시스템을 베이스로 RPG 어드벤처 + 수집 + 배틀을 추가한 **독립 신작**.

**플랫폼**: Web (Chrome/Edge 데스크탑) + Dot Pad (BLE/USB)
**상태**: GDD v0.2 (RPG 피벗 디자인 + UI 셸 v0.3 완료, 게임 로직 미구현)
**배포 URL**: https://baekjunjoo.github.io/dotpetmon/

---

## 핵심 디자인 필러 (v0.2)

1. **나는 주인공이다** — 플레이어 = 트레이너. 알 부화 → 모험 시작
2. **촉각 발견** — 새 종 만날 때마다 손끝으로 새 시그너처 만남 = 핵심 보상
3. **유대 = 힘** — 케어 스탯이 배틀 모디파이어 (`bond_mod 0.9~1.2`)
4. **여행이 곧 도감** — 8 지역 각자 다른 종, 도감 완성 = 게임 클리어

## 게임 시작 시퀀스

1. 트레이너 이름 입력 → 음성 인사
2. 알 수령 이벤트 (할머니/마을 어른이 줌)
3. 알 부화 미니게임 (리듬 입력)
4. 랜덤 스타터 공개 (4종 중 1: Pibbi / Chikapi / Bubloo / Mosshu)
5. 첫 지역 (Starter Plains) → 첫 야생 인카운트 → 첫 포획

## 스코프 (의도적 축소)

| 항목 | 포켓몬 | 닷펫몬 |
|---|---|---|
| 종 수 | 1000+ | 12 → 24 캡 |
| 타입 | 18 | 5 (Flame/Drop/Frond/Spark/Stone) |
| 월드 | 광활한 맵 | 메뉴식 6 지역 |
| 배틀 | 6 vs 6 파티 | 1 vs 1 (v1) → 3 vs 3 (v2) |
| 시각장애 접근성 | 불가능 | 1순위 타깃 |
