# 닷펫몬 나노바나나 프로 프롬프트 v0.3 (마누스용 간결판)

**도구**: Manus.im + Nano Banana Pro
**전제**: 사용자가 Cassette Beasts 풍 레퍼런스 이미지 첨부 → 톤/스타일은 자동 매칭
**프롬프트 원칙**: subject + 핵심 디테일만 (2-3줄). 스타일 디스크립터 생략.

---

## 사용법

1. 마누스에 레퍼런스 이미지 첨부 (Cassette Beasts 키 아트 등)
2. 아래 프롬프트 블록 하나씩 복사 → 생성
3. 4-8회 반복 → 베스트 선택
4. `dotpetmon-prototype/assets/illustrations/` 저장

## 9. v0.7 통합 시 코드 적용

생성된 일러스트는 다음 위치에서 사용:

| 일러스트 | 사용 위치 |
|---|---|
| 종 컬러 (10) | 타이틀 그리드 카드 / 도감 / 뷰포트 / 인카운트 / 배틀 |
| 트레이너 hero | 타이틀 hero 우측 (현재 닷패드 미리보기 자리 옆) |
| 지역 배경 (8) | exploring 화면 배경 (현재 색상만) |
| 알 5단계 | hatch 미니게임 (현재 픽셀만) |
| 닷패드 | 타이틀 푸터 / about 페이지 |
| 타입 배지 | 도감 / 인카운트 헤더 |
| 배틀 배경 | v1.0 배틀 화면 |

각 위치에 **CSS background-image** 또는 **<img> 태그**로 추가하면서 닷패드 픽셀 렌더는 그대로 유지 (시각장애 사용자는 닷패드 + 픽셀 미리보기, 비시각장애 사용자는 컬러 일러스트 위주로 봄).

## 10. 라이센스 안전

- Cassette Beasts 캐릭터 직접 모방 금지 (스타일만 차용)
- 포켓몬 IP 절대 금지
- 트레이너 = 접근성 디자인 (smart glasses + cane + Dot Pad) = 차별점
- 모든 종 = 우리 오리지널 픽셀 스프라이트의 컬러 버전

레퍼런스 이미지가 톤을 잡지만, **negative prompt에 "no copyrighted Pokemon, no Pikachu, no Nintendo IP"** 추가하면 더 안전.
