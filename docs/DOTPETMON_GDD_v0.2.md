## 1. 비전 + 디자인 필러

### 1.1 비전 문장 (v0.2)

> "시각장애 사용자가 처음으로 진짜 **모험**을 떠날 수 있는 게임. 내가 주인공이 되어, 알을 부화시키고, 여러 지역을 다니며 닷펫몬을 모은다."

### 1.2 4가지 필러

| # | 필러 | 의미 |
|---|---|---|
| 1 | **나는 주인공이다** | 플레이어 캐릭터 = 트레이너. 스토리는 내 것 |
| 2 | **촉각 발견** | 새 종을 잡을 때마다 손끝으로 새 시그너처 만남 = 핵심 보상 |
| 3 | **유대 = 힘** | 케어 시스템 (DotPet 베이스)이 배틀 모디파이어 |
| 4 | **여행이 곧 도감** | 지역마다 다른 종 → 모든 지역 방문 = 도감 완성 |

### 1.3 v0.1 대비 변경

| 영역 | v0.1 | v0.2 |
|---|---|---|
| 게임 무게중심 | 케어 60% + 배틀 30% + 수집 10% | 수집 50% + 배틀 30% + 케어 20% |
| 플레이어 정체성 | "닷패드 사용자" (추상) | "트레이너" (캐릭터) |
| 시작 | 펫 1마리 케어 | 알 부화 → 랜덤 스타터 → 모험 |
| 세계 | 추상적 (단일 화면) | 지역 8개 (메뉴식) |
| 메인 루프 | 분 단위 케어 + 회 단위 배틀 | 회 단위 탐험 + 수집 + 배틀 |

## 2. 코어 게임 루프

### 2.1 새 루프 (v0.2)

```
탐험 (지역 선택)
   ↓
인카운트 (랜덤 야생 등장)
   ↓
[배틀] 또는 [포획] 선택
   ↓
승리/포획 시
   ↓
도감 등록 + XP + 골드
   ↓
파티 케어 (회복 + 유대 유지)
   ↓
강해짐 → 새 지역 해금
```

### 2.2 시간 단위별 활동

| 단위 | 활동 | 빈도 |
|---|---|---|
| 분 (Encounter) | 한 지역에서 인카운트 1-3회 | 깨어있을 때 수시 |
| 회 (Run) | 한 지역 탐험 한 세션 (5-10분) | 매일 3-8회 |
| 일 (Care) | 파티 회복 + 케어 액션 | 매일 1-3회 |
| 주 (Progress) | 새 지역 해금, 진화, 도감 마일스톤 | 주 1-2회 |

## 3. 게임 오프닝

### 3.1 시작 시퀀스

1. **트레이너 생성**
   - 이름 입력 (TTS 받아쓰기 가능)
   - 음성 인사 ("안녕하세요, [이름]. 닷펫몬의 세계에 오신 걸 환영합니다.")
2. **알 수령 이벤트**
   - "할머니/스승/마을 어른"이 알 하나를 건네줌 (캐릭터 백그라운드 약식 음성 안내)
   - "이 알 안에 어떤 닷펫몬이 있을지는 아무도 모릅니다."
3. **부화 미니게임**
   - 닷패드에 알 풀스크린 표시 (둥근 형태)
   - F1을 리듬에 맞춰 누르기 (3-5회) — DotPet의 리듬 미니게임 재활용
   - 알이 깨지는 음성 + 사운드 + 닷패드 균열 애니메이션
4. **스타터 공개**
   - 4종 스타터 풀에서 랜덤 1마리 선택
   - 닷패드에 새 종 시그너처 풀스크린 표시 (5초)
   - 음성: "Pibbi입니다! 빛 타입 닷펫몬, 큰 둥근 귀와 별 꼬리를 가지고 있어요."
   - 이름 변경 가능
5. **튜토리얼**
   - 첫 지역 (Starter Plains)에서 첫 야생 인카운트
   - 배틀 시스템 음성 가이드
   - 첫 승리 → 첫 포획 → 도감 첫 등록

### 3.2 스타터 풀 (4종)

| 스타터 | 타입 | 특징 |
|---|---|---|
| **Pibbi** | Light | 빠른 공격, 낮은 방어 (Pikachu 포지션) |
| **Chikapi** | Fire | 강한 공격, 보통 방어 (Charmander 포지션) |
| **Bubloo** | Water | 균형형, 높은 HP (Squirtle 포지션) |
| **Mosshu** | Nature | 회복 기술, 느리지만 단단 (Bulbasaur 포지션) |

랜덤이므로 리롤 가능 (오프닝 1회만, "다시 부화" 옵션). 이후엔 야생에서 잡아야 함.

### 3.3 왜 알 + 랜덤인가

- **수집 동기 강화**: "내가 받은 스타터를 키운다" → 강한 유대
- **재플레이 가치**: 다른 스타터 받으려면 새 게임 (회차 시스템)
- **시각장애 친화**: 시각적 "고르기" 화면 대신 음성 "이번엔 어떤 친구일까?" 서스펜스
- **부화 미니게임** = 첫 닷패드 인터랙션 학습

### 4.2 지역 진입 시 음성 분위기

각 지역 진입 시 5-10초 음성 + 사운드 분위기:
- Starter Plains: "바람이 풀잎을 스치는 소리. 따뜻한 햇살."
- Whispering Forest: "안개가 자욱하다. 멀리서 누군가 속삭이는 듯하다."
- Ember Volcano: "발 밑에서 열기가 올라온다. 용암 흐르는 소리."
- Mirror Lake: "수면이 잔잔하다. 가끔 물고기가 튀어오른다."
- Storm Plain: "천둥소리. 머리카락이 곤두선다."
- Iron Cave: "발자국이 메아리친다. 차가운 공기."
- Sacred Grove: "오래된 나무들이 빛을 낸다. 신비로운 음악."
- Echo Sanctum: "당신의 모든 모험이 여기로 모인다."

→ 시각 의존 없이 분위기 전달

### 4.3 지역 내 활동

지역 진입 → 다음 중 선택:

| 행동 | 설명 |
|---|---|
| **탐험 (Walk)** | 30초-2분, 그동안 랜덤 인카운트 1-3회 발생 |
| **인카운트 강제** | 즉시 야생 1마리 (탐험 시간 X) |
| **도감 확인** | 이 지역에서 만난/포획한 종 확인 |
| **돌아가기** | 마을/홈 베이스로 복귀 |

탐험은 시간 기반 (실시간 30초) 또는 턴 기반 (F1 누를 때마다 1 스텝). 사용자 선택.

### 4.4 지역 해금 메커닉

- 도감 X종 등록 시 자동 해금
- 일부 지역은 추가 조건 (특정 종 보유, 진화 레벨 등)
- 해금 시 음성 알림 + 챔피언 펫에게 작은 보너스

## 5. 인카운트 + 포획 시스템

### 5.1 인카운트 플로우

1. 탐험 중 야생 등장 음성: "야생 Mosshu가 풀숲에서 나타났다!"
2. 닷패드: 야생 펫 시그너처 표시 + 추정 레벨 음성
3. 선택지 (음성 + 키):
   - **F1** — 싸움 (배틀 진입)
   - **F2** — 포획 시도 (Capture Ball)
   - **F3** — 도망 (성공률 90%)
   - **F4** — 정보 (타입, 추정 레벨, 알려진 약점)

### 5.2 포획 미니게임 (리듬 기반)

```
포획 성공률 = base × (1 - hp_ratio) × ball_modifier × rhythm_accuracy × type_match
```

- `base`: 종별 0.05 (희귀) ~ 0.6 (흔함)
- `hp_ratio`: 야생 현재 HP / 최대 HP (낮을수록 ↑)
- `ball_modifier`: 일반 1× / 특수 2× / 마스터 100×
- `rhythm_accuracy`: 리듬 시퀀스 정확도 (0.5 ~ 1.5)
- `type_match`: 같은 타입 펫 사용 시 1.2× 보너스

**리듬 시퀀스**: 야생 레벨에 따라 3-7 노트. F1-F4로 리듬 맞춰 입력. 야생 발버둥 = 시퀀스 빠르게 변화.

### 5.3 포획 성공 시 음성 시퀀스

1. "잡혔다!" 음성 + 캐치 사운드
2. 닷패드: 새 종 시그너처 5초 풀스크린 (특히 도감 첫 발견 시)
3. 음성 묘사: "Mosshu, 자연 타입. 물방울 모양 몸에 새싹이 머리에 자라있어요."
4. 도감 자동 등록
5. 파티 가입 또는 박스 보관 선택 (파티 6마리 풀이면 박스 강제)

### 5.4 포획 실패 시

- 야생이 탈출 → 배틀 계속 또는 다시 포획 시도
- HP는 그대로 유지 (포획 시도가 데미지를 주진 않음)
- 야생 도망 확률 ↑ (실패 누적 시)

## 6. 배틀 시스템

### 6.1 구조 (v0.1과 동일, 일부 정밀화)

- 1 vs 1 턴제
- 양측 4 기술 슬롯
- 평균 5-10턴
- 평균 1-3분 (TTS 속도 영향)

### 6.2 닷패드 화면 (60×40)

```
[row 0-1, full]    HP 바: 내 (좌 26 pin) / 상대 (우 26 pin)
[row 2-7, 0-29]    내 펫 미니 실루엣 (20W × 24H pin)
[row 2-7, 30-59]   상대 펫 미니 실루엣 (20W × 24H pin)
[row 8-9, full]    선택 기술 인덱스 (F1~F4 4분할) + 상태이상 아이콘
```

### 6.3 키 매핑

| 키 | 동작 |
|---|---|
| F1~F4 | 4 기술 선택+발동 |
| 패닝 ◀▶ | 기술 사이클 (음성 미리듣기) |
| 패닝 ▲ | 가방 (포션, 볼) |
| 패닝 ▼ | 펫 교체 |
| 패닝 ⊙ | 상황 요약 ("내 HP 32/45, 상대 HP 18/40") |
| F2 길게 | 상대 정보 (타입, 추정 레벨, 알려진 약점) |

### 6.4 데미지 공식 (v0.1 동일)

```
damage = (level × 0.4 + 2) × power × (atk/def) × type_mod × bond_mod × random(0.85, 1.0)
```

- `bond_mod`: 0.9 (방치) ~ 1.2 (최고 유대) — 케어 시스템 직결

### 6.5 보상

- **승리**: XP + 골드. 트레이너 배틀은 더 많이
- **레벨업**: 스탯 증가 + 새 기술 학습
- **타입 매치업 보너스 XP** (Light vs Dream 같은 약점 공격 시)

## 7. 케어 시스템 (DotPet 통합)

### 7.1 보조 시스템화

v0.1에서는 메인 시스템이었던 케어가 v0.2에서는 **보조 버프 레이어**로 이동.

| 케어 스탯 | 배틀 영향 |
|---|---|
| Energy 80+ | 선공 우선 |
| Love 80+ | 크리티컬 ×2 |
| Happy 70+ | 명중률 +10% |
| Clean < 50 | 상태이상 받기 +20% |
| Hunger < 20 | 매턴 HP 회복 안 됨 |
| Hunger 0 | 배틀 거부 ("배가 너무 고파요!") |

### 7.2 케어 액션 (홈 베이스 메뉴)

- **먹이** (F1): 골드 소비, hunger ↑, love ↑ (좋아하는 먹이는 보너스)
- **놀기** (F2): happy ↑, energy ↓, love ↑
- **씻기** (F3): clean ↑, happy ↓ (싫어함)
- **잠재우기** (F4): energy ↑↑

### 7.3 자동 케어

탐험 중 시간 흐름 → 케어 스탯 자연 감소. 홈 베이스에서 회복.

## 8. 도감 (DotDex)

### 8.1 구조

10종 슬롯:
- **미발견** (회색): "?"
- **만남 (Seen)**: 야생에서 만났지만 미포획 — 흐릿한 시그너처
- **포획 (Caught)**: 완전 등록 — 풀 시그너처 + 정보 + "패드에 보기" 가능

### 8.2 도감 정보 (포획 후)

각 종 페이지:
- 종 번호, 이름, 타입
- 촉각 묘사 (음성으로 읽기)
- 첫 포획 일자, 지역
- 보유 마리 수, 평균 레벨
- 시그너처 사운드 재생 버튼
- "패드에 보기" — 닷패드에 풀스크린 표시

### 8.3 도감 진척도 마일스톤

| 진척 | 보상 |
|---|---|
| 3/10 | 고급 볼 ×5 |
| 5/10 | 진화석 ×1 |
| 7/10 | 특수 회복약 ×3 |
| 10/10 (완성) | 음성 칭호 "도감 마스터" + 챔피언 펫 골드 액세서리 |

## 9. 진화 (Evolution)

### 9.1 단계 (v0.1과 동일 구조)

10종 중 진화 가능한 종 vs 단일 형태 종 결정 필요.

**제안**: 10종 모두 진화 가능 (각 3단계). 36 스프라이트 추가 필요 (현재 10개) — **v0.3+ 작업**.

또는 일부만 진화 (예: 스타터 4종 + 일부) → 스프라이트 부담 ↓.

### 9.2 진화 조건

- 기본: 레벨 14 (Baby→Child), 28 (Child→Adult)
- 케어 의존: love 70 이상
- 특수 진화 (v2.0+): 트레이드 진화, 돌 진화, 시간 진화

## 17. 핵심 비전 정리

> **"내가 받은 알에서 부화한 첫 친구와 함께, 여러 지역을 다니며 닷펫몬을 모은다."**

3가지 감동 모먼트:
1. **부화의 순간** — 어떤 친구일까? 손끝으로 처음 만나는 시그너처
2. **새 지역 진입** — 음성 분위기 + 닷패드에 새 환경 패턴
3. **새 종 포획** — 도감 등록 + 시그너처 첫 발견 = 핵심 보상

이 3가지가 작동하면 게임은 성공.
