# 마누스 브리프 — 닷펫몬 일러스트 일괄 생성

**용도**: 마누스에 작업 요청할 때 맨 위에 붙이는 컨텍스트 + 지침.
**다음**: `NANO_BANANA_PROMPTS_v0.3.md` 의 프롬프트 블록들을 이어서 붙임.

---

## 추천 워크플로우 (3단계로 분할)

마누스에 한 번에 다 던지지 말고 단계별로:
1. **1단계**: 종 10개만 (가장 중요)
2. **2단계**: 트레이너 3 포즈 + 닷패드 디바이스
3. **3단계**: 지역 배경 8개 + 알 + 타입 배지

각 단계 결과 톤 컨펌 후 다음으로.

## ✂️ 마누스에 붙일 텍스트 (1단계 — 종 10종)

```
안녕! 닷펫몬(DotPetMon)이라는 게임의 캐릭터 일러스트 10종을 만들고 싶어.

【프로젝트 컨텍스트】
- 게임: 시각장애 친화 턴제 몬스터 수집 RPG
- 타깃: 시각장애 사용자 + 비시각장애 사용자 함께 즐기는 co-play 디자인
- 캐릭터들은 모두 오리지널 (포켓몬 IP 모방 절대 금지)

【비주얼 스타일】
첨부한 레퍼런스 이미지 (Cassette Beasts 풍) 의 스타일을 그대로 유지해줘:
- 굵고 가변 두께의 검은 외곽선 + 흰색 sticker 보더
- 채도 높은 파스텔 컬러 (purple/blue/yellow/orange/pink/mint)
- Y2K + 90s 애니메 감성
- 스티커 아트 느낌, 동적인 포즈
- Flat shading + 미묘한 하이라이트

【출력 요구사항】
1. 각 프롬프트당 4번 생성 → 가장 좋은 1개 선택해서 알려줘
2. 모두 1:1 정사각형, 투명 배경 (transparent PNG)
3. 사이즈 1024×1024
4. 파일명: pibbi.png, mosshu.png, voltchi.png 등 (소문자 영문)
5. 10종 전체 톤 일관성 유지 — 같은 일러스트 시리즈로 보이게

【품질 체크리스트】
- ✅ 각 종의 시그너처 특징이 명확히 보임 (귀 크기, 꼬리 모양, 날개 등)
- ✅ 친근하고 귀여운 톤
- ✅ 외곽선이 깔끔하고 stickerable
- ❌ 포켓몬 캐릭터 모방 (Pikachu, Charmander, Wailord 등 절대 X)
- ❌ 사실주의 / 어두운 톤 / 무서운 분위기

【생성할 10종】
아래 10개 프롬프트를 순서대로 생성해줘:

[여기에 NANO_BANANA_PROMPTS_v0.3.md 의 1.1 ~ 1.10 (Pibbi ~ Luminoa) 프롬프트 10개를 순서대로 붙여넣기]

【최종 결과물】
10개 PNG 파일을 ZIP으로 묶어서 다운로드 링크 주세요. 톤이 안 맞는 게 있으면 어떤 게 다르고 왜 그런지 한 줄로 알려주세요.
```

## ✂️ 2단계 — 트레이너 + 닷패드

```
안녕! 어제 만든 닷펫몬 종 10개 잘 받았어 (이전 대화 연속).
이번엔 같은 스타일로 트레이너 캐릭터 3 포즈 + 닷패드 디바이스를 만들어줘.

【스타일】
첨부 레퍼런스 동일. 종 10종과 톤 100% 매칭 필요.
같은 시리즈로 보이게 일관성 최우선.

【트레이너 캐릭터 (3 포즈)】
같은 캐릭터를 3가지 포즈로:
- 영웅 포즈 (3:4 portrait, 타이틀 화면용)
- 액션 포즈 (1:1, 점프 중)
- 헤드샷 (1:1, 얼굴 클로즈업)

캐릭터는 inclusive accessibility 디자인 — 시각장애 표현 자연스럽게 (smart glasses + 가이드 케인 + 백팩의 닷패드).

【닷패드 디바이스 1개】
실제 닷 인코퍼레이션 닷패드 디바이스 일러스트 (촉각 점자 디스플레이).

【출력】
- 트레이너 3개: hero.png (3:4), action.png (1:1), headshot.png (1:1)
- 닷패드: dotpad-device.png (3:2)
- 모두 투명 배경, 1024px 사이즈
- 각 프롬프트당 4번 생성 후 베스트 1개 선택

[여기에 NANO_BANANA_PROMPTS_v0.3.md 의 2.1 ~ 2.3 + 5번 프롬프트 4개 붙여넣기]

【확인】
트레이너의 옷 색깔이 종 10종과 같은 팔레트인지 (특히 purple #AFA9EC + orange #ff7a45) 확인 부탁.
```

## ✂️ 3단계 — 배경 + UI

```
안녕! 닷펫몬 캐릭터들 (종 10 + 트레이너 + 닷패드) 잘 받았어 (이전 대화 연속).
이번엔 환경 배경 8개 + 알 5단계 + 타입 배지 시트를 만들어줘.

【스타일】
첨부 레퍼런스 동일. 종/트레이너 일러스트와 함께 화면에 배치될 거니까 톤 매칭 중요.

【배경 (8 지역)】
사람/몬스터 없는 환경 풍경. 16:9 widescreen, 1920×1080.
캐릭터가 위에 올라가도 어색하지 않을 정도로 디테일은 적당히 (너무 화려하지 않게).

【UI 요소】
- 알 5단계 시트 (부화 진행 5단계, 5:1 가로)
- 타입 배지 10개 시트 (5×2 그리드)

【출력】
- 8 지역 배경: starter-plains.png, whispering-forest.png, ember-volcano.png,
  mirror-lake.png, storm-plain.png, iron-cave.png, sacred-grove.png, echo-sanctum.png
- egg-stages.png (5:1)
- type-badges.png (5:2)
- 모두 투명 배경 가능한 곳은 투명, 배경은 풀 컬러
- 각 프롬프트당 4번 생성 후 베스트 1개

[여기에 NANO_BANANA_PROMPTS_v0.3.md 의 3.1 ~ 3.8 + 4 + 6 프롬프트 10개 붙여넣기]

【최종 결과물】
ZIP으로 묶어서 주세요. 시리즈 일관성 평가도 한 줄 부탁드립니다.
```

## 일관성 팁 (마누스에게 추가로 강조하면 좋은 것)

마누스가 알아서 처리하지 못할 수 있는 부분:

```
【중요 일관성 규칙】
1. 모든 생성물은 같은 "시리즈" 느낌이어야 함 — 각각 다른 작가가 그린 느낌이면 안 됨
2. 첫 번째 결과의 시드 / 스타일을 기억해두고 나머지에 일관 적용
3. 색상 팔레트 고정:
   - Primary: orange #ff7a45 / purple #AFA9EC / cyan #4dc4d8
   - Type colors: Light yellow #FAC775, Nature green #97C459, Electric #F2C14E,
     Water #85B7EB, Earth #D85A30, Fire #E24B4A, Metal #888780,
     Dream purple #AFA9EC, Sound pink #F4C0D1, Spirit mint #9FE1CB
   - Outlines: deep navy #1A1F3A
4. 외곽선 두께는 모든 일러스트에서 비슷하게 (varied weights, but consistent ratio)
5. 흰색 sticker border는 항상 있음 (3-5px)
6. 그림자/하이라이트 스타일도 동일 (single flat shadow, single soft highlight)
```

## 변경 요청 시 (생성 후 일부만 수정)

```
[종 이름] 일러스트 조금 수정 요청:
- 현재: [어떤 부분이 어떻게 보이는지]
- 변경: [어떻게 바꾸고 싶은지]
- 다른 부분 (외곽선, 색상 톤)은 그대로 유지
- 시리즈 일관성 깨지지 않게 같은 스타일로

예시:
"Pibbi의 별 꼬리가 너무 작아서 잘 안 보여. 별 크기를 1.5배로 키우고 약간 더 노란 글로우 추가해줘. 나머지 (귀/몸/색상)는 그대로."
```
