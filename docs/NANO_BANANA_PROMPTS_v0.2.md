# 닷펫몬 나노바나나 아트 프롬프트 v0.2 (한 번에 복붙)

**스타일 레퍼런스**: Cassette Beasts — New Wirral Edition 키 아트
**모델**: Google Gemini 2.5 Flash Image (Nano Banana)
**사용법**: 각 프롬프트 블록은 self-contained. 그대로 복사해서 나노바나나에 붙여넣으면 됨.

---

## 사용 가이드

- 각 프롬프트는 **공통 스타일 + 색상 팔레트 + 네거티브가 모두 인라인**되어 있어 따로 합칠 필요 없음
- 우선순위 추천: **1.1 → 2.1 → 3.2 → 4.1~4.10 → 6.x → 5.x**
- 같은 프롬프트 4-8회 반복 생성 후 베스트 선택
- 결과물은 `assets/illustrations/` 에 저장 → v0.4 프로토타입에서 사용

### 8.2 생성 팁

- **씨드 고정**: 첫 결과 마음에 들면 같은 seed로 다른 변형 만들기
- **4-8회 반복**: 같은 프롬프트 여러 번 → 베스트 1개 선택
- **부분 수정**: 결과 마음에 들면 specific 디테일만 수정 ("change Pibbi's ears to slightly bigger")
- **레퍼런스 첨부**: Cassette Beasts 키아트를 같이 첨부하면 톤 매칭 잘됨
- **배경 분리**: 캐릭터는 배경 투명/단색으로 → 후처리에서 합성

### 8.3 후처리

- 모든 PNG → 배경 투명 처리 (Photoshop/Figma/remove.bg)
- 일러스트는 **1024×1024** 또는 **2048×2048** 권장
- 게임 내에서 다운스케일해서 사용
- 최종 저장: `assets/illustrations/` 폴더 (생성 후)
