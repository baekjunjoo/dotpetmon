## 1. 비전 + 디자인 필러

### 1.1 비전 문장

> "시각장애 사용자가 처음으로 진짜 '내 동료'를 가질 수 있는 게임. 만지고, 키우고, 같이 싸우고, 친구와 나눈다."

### 1.2 3가지 필러

| # | 필러 | 의미 | 시각 의존성 |
|---|---|---|---|
| 1 | **촉각 정체성** | 각 종은 60×40 핀 위 고유 시그너처. 손끝으로 인식 | 0% (시각 보조만) |
| 2 | **케어 = 힘** | 잘 키운 펫일수록 강함. 단순 레벨링이 아닌 유대 시스템 | 0% |
| 3 | **사회적 연결** | 트레이딩으로 친구가 키운 펫의 촉각을 처음 만지는 순간 = 핵심 감동 | 0% |

### 1.3 의도적으로 만들지 않는 것

- 시각 의존 액션 (월드맵 워킹, 실시간 회피)
- 화려한 애니메이션이 핵심 보상인 시스템
- 캐릭터 외형이 강점인 디자인 (촉각/사운드/이름이 강점)

## 2. 코어 게임 루프

### 2.1 시간 단위별 활동

| 단위 | 활동 | 빈도 |
|---|---|---|
| 분 (Care) | 먹이/놀이/씻기/잠 — DotPet 시스템 유지 | 깨어있을 때 수시 |
| 회 (Battle) | 배틀 한 판 1-3분 | 매일 5-10회 |
| 일 (Progress) | 진화, 새 기술 학습, 새 야생 발견 | 매일 1-3회 |
| 주 (Social) | 친구와 트레이드, 주간 랭킹, 챌린지 | 주 1-2회 |

### 2.2 사용자 여정

1. **첫 30분**: 알 부화 → 베이비 펫 케어 → 첫 야생 인카운터 → 첫 포획 → 첫 배틀 승리
2. **첫 1주**: 진화 1단계 도달 → 5타입 학습 → 도감 5종 등록 → 첫 트레이드
3. **첫 1개월**: 어덜트 진화 → 도감 12종 풀 → 친구와 정기 트레이드 → 일일 챌린지 루틴
4. **장기 (3개월+)**: 도감 풀 컬렉션 + 유대 만랩 펫 1-2마리 + 트레이드 커뮤니티 활동

## 3. 종 (Species) 디자인 시스템

### 3.1 규모

- **1차 출시 (v1.3)**: 12종 × 3진화 단계 = **36 스프라이트**
- **2차 (v2.0+)**: 18종까지 확장
- **장기 목표**: 24종 캡 (그 이상은 손끝으로 구분 어려움)

### 3.2 촉각 시그너처 원칙

각 종은 다음 3축으로 차별화되어야 함:

#### 축 1 — 실루엣 카테고리 (총 6개)
1. **둥근형** (Round): 슬라임, 알, 두꺼비 — 좌우대칭 둥근 윤곽
2. **길쭉형** (Elongated): 뱀, 물고기, 새 — 수평으로 긴 윤곽
3. **사족보행** (Quadruped): 강아지, 도마뱀 — 4발 + 머리 + 꼬리
4. **이족보행** (Biped): 토끼, 곰 — 직립 + 팔 2개
5. **비행/날개** (Winged): 새, 박쥐 — 양옆 큰 돌출 (날개)
6. **식물/결정** (Plant/Crystal): 새싹, 광물 — 비대칭 돌출 (잎/결정)

#### 축 2 — 특징 1개 강조
귀, 뿔, 꼬리, 날개, 잎, 등껍질 중 1개를 두드러지게 디자인. 손끝 1차 식별점.

#### 축 3 — 표면 텍스처
- 매끈 (둥근 솔리드)
- 줄무늬 (가로 줄)
- 점박이 (격자 점)
- 거친 (불규칙 융기)

→ 6 × 6 × 4 = **144 가능 조합**, 실제 24종까지는 충분히 구분 가능

### 3.3 음성 시그너처

각 종 1-2초 고유 울음. Web Audio 신디로 생성:
- 음정 패턴 (3-5음 시퀀스)
- 리듬 (점박이 / 트릴 / 글라이드)
- 팀버 (sine / square / triangle / sawtooth)

→ 닷패드 미연결 사용자도 청각만으로 종 인식 가능

### 3.4 이름 + 분류

각 종 3진화 단계 모두 오리지널 이름. 분류명도 (예: "Ember the Fire Pup", "Cinder the Flame Hound", "Pyrekin the Ember Warden")

## 5. 배틀 시스템

### 5.1 구조

- **1 vs 1 턴제** (포켓몬 동일)
- 양측 4기술 슬롯
- 양측 단일 펫 (파티 시스템은 v2.0+)
- 평균 5-10턴 / 배틀
- 평균 배틀 길이 1-3분 (TTS 속도 영향)

### 5.2 닷패드 화면 (60×40)

```
[0-39, row 0-1]    HP bars: 내 (좌 26핀) / 상대 (우 26핀)
[0-29, row 2-7]    내 펫 미니 실루엣 (20W × 24H pin)
[30-59, row 2-7]   상대 펫 미니 실루엣 (20W × 24H pin)
[0-59, row 8-9]    선택된 기술 1-4 표시 + 상태이상 아이콘
```

### 5.3 키 매핑

| 키 | 동작 |
|---|---|
| **F1~F4** | 4개 기술 선택+발동 |
| 패닝 ◀▶ | 기술 사이클 (음성으로 효과 미리듣기, 발동 X) |
| 패닝 ▲ | 가방 (포션, 볼) |
| 패닝 ▼ | 도망 |
| 패닝 ⊙ (중앙) | 현재 상황 요약 ("내 HP 40, 상대 HP 70, 내 차례, 화상 상태") |
| F2 길게 | 상대 펫 상세 (타입, 추정 레벨, 알려진 약점) |

### 5.4 데미지 공식

```
damage = (level × 0.4 + 2) × power × (atk / def) × type_mod × bond_mod × random(0.85, 1.0)
```

- `power`: 기술 위력 (40~120)
- `type_mod`: 0.5 / 1.0 / 2.0 (타입 상성)
- `bond_mod`: 0.9 (방치) ~ 1.2 (최고 유대) — 케어 시스템 직결

### 5.5 상태이상

| 상태 | 효과 | 회복 |
|---|---|---|
| 화상 (Burn) | 매턴 최대 HP 8% 감소, 공격력 -25% | 5턴 또는 도구 |
| 마비 (Paralyze) | 25% 확률 턴 스킵, 스피드 -50% | 4턴 또는 도구 |
| 잠 (Sleep) | 1-3턴 행동 불가 (랜덤) | 자동 |
| 씨앗 (Seed) | 매턴 사용자가 HP 10% 흡수 | 영구 (펫 교체로만) |
| 둔화 (Slow) | 스피드 -75% | 3턴 |

### 5.6 음성 안내 (필수)

- 매 턴 시작: "당신 차례. 기술을 선택하세요. F1 불꽃펀치 70, F2 가르기 50, F3 화염방사 90, F4 쉬기"
- 기술 발동: "Ember가 불꽃펀치! Tidefin에게 24 데미지! 효과가 별로다."
- 상태이상: "Ember가 마비 상태!"
- 승패: "Tidefin 쓰러짐! Ember 승리! XP 42 획득!"

## 6. 포획 (Catch) 시스템

### 6.1 탐험 메뉴

월드맵 없음. 대신 메뉴 기반:

```
탐험 지역 선택:
1. 풀숲 (Frond/Drop 자주 출현, 레벨 3-8)
2. 화산 (Flame 위주, 레벨 5-12)
3. 호수 (Drop 위주, 레벨 4-10)
4. 동굴 (Stone/Spark, 레벨 6-15)
5. 폭풍 평원 (Spark, 레벨 8-18)
6. 고대 숲 (희귀 종, 레벨 10-25) — 도감 5종 등록 후 해금
```

### 6.2 인카운터 플로우

1. 지역 선택 → 5-15초 음성 분위기 ("바람 소리, 풀잎 흔들리는 소리")
2. 야생 인카운터 시 닷패드에 야생 펫 실루엣 표시
3. 음성: "야생 Bubble이 나타났다! Drop 타입, 추정 레벨 6"
4. 선택지:
   - **F1**: 싸움 (배틀로 진입)
   - **F2**: 포획 (Capture Ball 사용, 첫 시도 약 30% 성공)
   - **F3**: 도망

### 6.3 포획 미니게임

DotPet의 리듬 게임 재활용 + 확장:

```
포획 성공률 = base_rate × (1 - hp_ratio) × ball_modifier × rhythm_accuracy
```

- `base_rate`: 종별 (흔한 종 0.6, 희귀 0.2, 전설 0.05)
- `hp_ratio`: 야생 현재 HP / 최대 HP (낮을수록 잘 잡힘)
- `ball_modifier`: 일반 1× / 특수 2× / 마스터 100×
- `rhythm_accuracy`: 미니게임 정확도 (0.5 ~ 1.5 배수)

리듬 시퀀스:
- 시퀀스 길이 = 야생 레벨 / 3 (3-7 노트)
- 야생 발버둥 = 시퀀스 빠른 변화
- F1-F4로 입력
- 모두 맞추면 포획, 1개 틀리면 야생 탈출 (HP 회복은 아님)

## 8. 유대 시스템 (DotPet 케어 → 배틀)

### 8.1 직결 매핑

DotPet 5개 스탯이 배틀에 영향:

| 스탯 | 영향 | 임계점 |
|---|---|---|
| Energy | 80+ = 선공 우선, 30↓ = 후공 강제 | 80 / 30 |
| Love | 80+ = 크리티컬 확률 2배, 40↓ = 5% 명령 무시 | 80 / 40 |
| Happy | 70+ = 명중률 +10%, 30↓ = -10% | 70 / 30 |
| Clean | 50↓ = 상태이상 받을 확률 +20% | 50 |
| Hunger | 20↓ = 매턴 HP 회복 못함, 0 = 배틀 거부 | 20 / 0 |

### 8.2 의미

- 같은 종 같은 레벨끼리도 큰 차이 발생
- "강함 = 시간 + 사랑"이라는 메시지
- 단순 갈기 게임이 아닌 진짜 유대 게임
- 시각장애 사용자가 보호자 역할에서 느낄 수 있는 감정 강화

### 8.3 유대 도구 (v1.5+)

- 좋아하는 먹이 (종별 다름) = love +5 / 한 번
- 함께 시간 보내기 (Bond 미니게임) = love +3 / 5분
- 챔피언 펫 (love 100) = 보너스 효과 (회복 +10%)

## 9. 트레이딩

### 9.1 v1.0 — 코드 기반

- **내보내기**: 펫 → 64자 영숫자 코드 생성
  - 인코딩: 종 ID (8bit) + 레벨 (8bit) + 스탯 5개 (각 8bit = 40bit) + 기술 4개 (각 8bit = 32bit) + 개체값 (16bit) + 이름 (가변, base64) → checksum
  - 예: `DPM-MOUSE-L18-X4A2F7-PYRE-EMB42-CK9` (청크 단위, 음성 받아쓰기 친화)
- **받기**: 코드 입력 → 검증 → 펫 추가
- **검증**: checksum + 합법성 (레벨/스탯 한계)

### 9.2 v2.0 — BLE Peer

닷패드 BLE를 통한 직접 P2P 트레이드:
- 두 사용자 닷패드 페어링
- 자동 코드 교환
- 트레이드 애니메이션 (양 닷패드 동기화)

### 9.3 트레이드 시 특별 경험 (핵심 UX)

받은 펫의 첫 만남:
1. "새 친구가 도착했습니다!" 음성 + 시그너처 사운드
2. 받은 펫 촉각 시그너처 닷패드에 5초간 표시
3. 음성: "[종 이름]이에요. [친구 이름]가 [레벨]까지 키웠어요. 만져보세요."
4. 처음 만나는 종이면 도감 등록 + 발견 음악
5. F1 누르면 이름 변경 가능

→ 이 순간이 닷펫몬의 핵심 감동 모먼트

## 10. 진척도 시스템

### 10.1 레벨업

- XP per win = (상대 레벨 × 8) × type_bonus × bond_bonus
- 레벨업 시 스탯 증가 + 새 기술 학습 트리거
- 1 → 50 만렙 (만렙은 v2.0+에서 풀림)

### 10.2 도감 (DotDex)

- 만난 종 / 포획한 종 카운트
- 각 종의 촉각 시그너처 라이브러리
- "패드에 보기" 기능: 도감에서 종 선택 → 닷패드에 해당 종 풀스크린 시그너처 표시
- 음성 묘사: "Ember는 둥근 머리에 뾰족한 귀 두 개, 작은 꼬리에 불꽃"

### 10.3 일일 / 주간 챌린지

| 챌린지 | 보상 |
|---|---|
| 일일: 야생 3마리 만나기 | 100 골드 |
| 일일: 배틀 5승 | 일반 볼 ×3 |
| 주간: 특정 타입 10승 | 특수 볼 ×1 |
| 주간: 트레이드 1회 완료 | 진화석 ×1 |

### 10.4 마일스톤 (시각 배지 대신)

- "10마리 친구가 된 트레이너"
- "100승 달성"
- "도감 50% 완료"
- "트레이드 10회"
- 각 마일스톤 = 음성 타이틀 + 챔피언 펫 골드 액세서리 (촉각으로도 인식 가능)

## 13. 접근성 최우선 원칙

### 13.1 절대 원칙

- 모든 정보는 음성으로 노출 가능
- 모든 인터랙션은 키보드 + 닷패드만으로 완료 가능
- 시각 정보는 항상 보조, 절대 유일 채널 아님
- 시간 압박 액션 없음 (리듬 미니게임은 충분히 느린 BPM)
- 색상 의존 0% (타입은 이름과 사운드로 구별)
- 닷패드 미연결 시에도 게임 100% 플레이 가능 (시각 표시 + 음성으로 대체)

### 13.2 음성 시스템

- 음성 속도 조절 (0.5×~2.0×)
- 음성 OFF 모드 (사운드만)
- "촉각 도움말" 기능: F4 길게 누르면 현재 닷패드 패턴 음성 묘사 ("화면 위쪽 왼쪽에 둥근 형태, 양옆에 뾰족한 귀")

### 13.3 학습 곡선

- 첫 30분 튜토리얼: 1개 액션씩 음성 안내
- 모든 메뉴에 "도움말" 단축키
- 키 매핑 카드 (음성으로 재생)

### 15.2 v0.2 디자인 변경 사항 (v0.1 대비)

| 항목 | v0.1 | v0.2 |
|---|---|---|
| 종 수 | 12 (Ember, Bubble 등 가제) | 10 (사용자 채택 컨셉) |

- 사용자가 디자인한 10종이 실루엣 측면에서 매우 강한 차별화 (각자 명확하게 다른 카테고리)

- 진화 단계는 일단 제외해서 PoC 빠르게 — 진화는 차별점이 아니라 보조 시스템

### 15.3 스프라이트 구현

- 위치: `dotpetmon-prototype/assets/species_sprites.js`
- 각 종: procedural drawing (oval / line / pin 단위)
- 캔버스: 60×40 핀
- 시각 검증: 위젯 갤러리로 10종 동시 비교 완료 (v0.2 작업)

## 17. 비교 분석 — Pokémon vs 닷펫몬

| 항목 | Pokémon (참고) | 닷펫몬 (목표) |
|---|---|---|
| 종 수 | 1000+ | 12 → 24 캡 |
| 타입 | 18 | 5 |
| 월드 | 광활한 맵 | 메뉴식 6 지역 |
| 배틀 | 6 vs 6 파티 | 1 vs 1 (v1) → 3 vs 3 (v2) |
| 진화 | 단계 + 분기 | 동일 |
| 트레이드 | 케이블 → 인터넷 | 코드 → BLE |

| 캐릭터 정체성 | 시각 (그림) | 촉각 + 음성 |
| 케어 시스템 | 우정 (제한적) | 핵심 시스템 (배틀 직결) |

→ 닷펫몬은 "포켓몬의 접근성 버전"이 아니라 "촉각/음성 우선 차세대 컬렉션 RPG"
