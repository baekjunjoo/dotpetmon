# 닷펫몬 (DotPetMon)

**Tamagotchi × Pokémon 접근성 게임 — DotPet 후속작**

시각장애 사용자를 위한 컬렉션 RPG. 닷패드 위 촉각 시그너처로 종을 인식하고, 키운 펫으로 턴제 배틀하며, 친구와 트레이드하는 게임.

> ℹ️ **DotPet과의 관계**: DotPet은 다마고치 스타일 케어 게임 (v0.9 라이브).
> 닷펫몬은 그 케어 시스템을 베이스로 배틀/포획/도감/트레이드를 추가한 **독립 신작**.

**플랫폼**: Web (Chrome/Edge 데스크탑) + Dot Pad (BLE/USB)
**상태**: GDD v0.1 (디자인 단계, 프로토타입 미구현)
**배포 URL (예정)**: https://baekjunjoo.github.io/dotpetmon/

---

## 핵심 디자인 필러

1. **촉각 정체성** — 각 종은 60×40 핀 위 고유 시그너처
2. **케어 = 힘** — 잘 키운 펫일수록 강함 (`bond_mod 0.9~1.2`)
3. **사회적 연결** — 트레이드로 친구가 키운 펫을 처음 만지는 감동

| 항목 | 포켓몬 | 닷펫몬 |
